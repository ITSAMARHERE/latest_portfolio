# Portfolio Engineering Guidelines

Guidelines and best practices for the Amar Pal Portfolio codebase:

- **Single Source of Truth**: All content, project descriptions, skills, and links reside in `src/data/portfolio.ts`.
- **Styling Architecture**: Built with modern Tailwind CSS and custom design tokens in `src/styles.css`.
- **Type Safety**: Maintain strict TypeScript typing across all components.
- **Visual Excellence**: Dark & light theme support, kinetic typography, and fluid micro-interactions.
